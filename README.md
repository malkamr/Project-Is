# AI Web Project 🤖

An interactive website that explores artificial intelligence concepts and real-world applications in a simple and engaging way.

## 🌍 Overview

This project aims to provide a clear introduction to AI, including its importance, uses, and impact on modern technology. It was developed as a collaborative team project.

## 🚀 Features

* Clean and responsive UI
* Simple explanation of AI concepts
* Interactive elements using JavaScript
* Beginner-friendly content

## 🛠 Tech Stack

* HTML
* CSS
* JavaScript
